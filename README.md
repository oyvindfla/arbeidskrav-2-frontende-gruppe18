# Turlyst

React-klient for Turistforeningen i Utopia, laget som studentoppgave ved USN. Inneholder søk etter turer og hytter, kart, favoritter, fellesturer og demonstrasjon av profil og annonseportal. Eksempeldata og lokale endringer lagres i nettleseren; dette er ikke en ferdig tjenerløsning.

## Start

Krever Node.js 22.12 eller nyere.

```sh
cd "Arbeidskrav 2/turapp"
npm install
npm run dev
```

Åpne adressen som vises i terminalen. `npm run build` lager produksjonsbygget.
